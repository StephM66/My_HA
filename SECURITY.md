# Sécurité

## Signaler un problème

Si vous trouvez un problème de sécurité, par exemple un script qui pourrait faire fuiter des données ou désactiver une protection, **n'ouvrez pas d'issue publique**. Utilisez **Security › Report a vulnerability** sur ce dépôt (signalement privé GitHub).

## Ce dépôt ne contient aucun secret

- Aucun mot de passe, jeton, clé API, adresse ni identifiant personnel.
- Les entités des exemples sont fictives.
- Les clés (OpenAI, etc.) se configurent dans les intégrations Home Assistant, jamais dans ces fichiers. Utilisez `!secret` dans votre propre configuration.

## Ce que vous copiez s'exécute chez vous

Lisez le code avant de l'installer. Aucun script de ce dépôt ne commande d'alarme, de serrure ou de porte de garage.
