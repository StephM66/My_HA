# My_HA

Projets Home Assistant, prêts à copier dans l'interface et à adapter à votre maison.

| Projet | Description |
|---|---|
| [Juge IA des notifications](juge-ia-notifications/) | Le cerveau des notifications : une IA (AI Task) décide si, quand et comment prévenir, puis diffuse par vos canaux (voix, téléphones, Telegram…) avec replis. Le débrief raconte le soir ce qui a été gardé. Blueprints importables en un clic. |

Chaque projet a son README : prérequis, installation pas à pas, réglages.

## Avant de copier

- Le code a été testé sur un banc Home Assistant, pas sur votre installation. Testez d'abord depuis **Outils de développement › Actions**.
- Remplacez les entités des exemples par les vôtres.
- Les projets qui utilisent une IA en ligne y envoient du contexte : lisez la section « Vie privée » de chaque README.
